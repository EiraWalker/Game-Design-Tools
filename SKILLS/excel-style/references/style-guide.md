# 通用 Excel 样式规则

本文维护跨工作簿适用的编辑原则。主题配色、字体和具体尺寸，以及表格布局记录，统一放在 [工作簿配置与布局参考](workbook-profile.md)。

## 标题与角色

- 按语义区分工作表主标题、章节标题与章节内小标题。行号、背景色和合并宽度只辅助判断层级。
- 同一工作簿中，相同角色使用一致的视觉含义；颜色用于表达标题、输入、计算结果和说明。
- 既有区域优先复制相邻同角色样式。保留现有字体和加粗状态，修改行高时保留字号。
- 表头显示行数包括手动换行和当前列宽下的自动换行；整行按其中最高的单元格适配，遵循工作簿确认的单行或多行表头设置。
- 主标题和说明通常左对齐，表头居中，连续数值通常右对齐；以所在表格已确认的用途和对齐方式为准。

## 输入、结果与不适用

- 根据是否可配置、是否派生计算选择输入或结果角色；「待定」表达内容状态，单元格颜色继续表达数据角色。
- 说明区域沿用正文背景；数学表达式的背景覆盖完整展示区，参数解释按各自角色处理。
- 保留逻辑列间的横竖分隔线；合并区域作为一个逻辑单元格，不在其内部添加分隔线。
- 零值、待定、空白与不适用具有不同含义，根据字段规则分别保留。
- 工作簿采用斜线表示不适用时，保留空内容与周围边框，使用左上到右下的单条斜线边框（`diagonalDown`）。

## 数值与布局

- 保留底层数值、类型、精度与计算公式。百分比等显示格式独立于存储值；单位沿用字段定义。
- 复制格式时保留目标内容与公式，检查缩进、换行和数字格式是否仍对应字段用途。
- 列宽根据短标签、参数和长说明的用途设置。局部修改只适配相关范围；保留章节留白、合并范围与冻结窗格。
- 合并单元格及浮动数学对象的高度，以实际显示或导出预览检查；自动适应行高的结果需要核实。
- 扩展区域时使标题色带和边框连续，保留各分区自身的合并结构。

## 数学结构

- 行内字母、希腊符号和单层上下标使用真实单元格富文本；二维数学表达式使用可编辑原生数学对象。
- 分别保留展示表达式、单元格富文本与计算公式。数学字体和参数符号随原有数学排版保留。
- 选择支持既有原生对象的编辑方法，保存后核对对象内容、位置及可编辑结构，必要时检查保存文件中的数学对象。
- 对象默认保持原宽度、所属展示区和锚定关系；适配公式行高时同步调整高度和垂直位置。

### 公式展示区行高

适用于任何工作表中的公式展示区；表头按表头规范处理。

1. 识别单行、分式、分段或多行结构，读取实际字体、字号、内容高度及文本框内边距。保留字号，通过承载行与公式框适配展示空间。
2. 以「公式内容高度 + 文本框上下内边距 + 展示区上下留白」估算展示区总高度。留白、取整步长和参考行高从工作簿配置读取；原生对象的测量值可辅助判断，最终以显示完整为准。
3. 同步设置公式框高度和垂直位置，使公式在完整展示区内居中、上下留白接近。行高变化后检查下方公式与说明对象仍在各自所属区域。
4. 公式跨多行时按这些行的总高度计算，一起适配承载公式的空白着色行；保留已有行、合并结构及说明内容。
5. 保存后通过 Excel 显示、截图或导出预览检查上下边缘、分式、括号、上下标和分段结构，确认没有裁切、遮挡或错位。同时核对公式内容、字体、配色和计算公式保留。

## 检查与维护

检查修改范围的标题层级、角色颜色、表头显示、分隔线、单位、合并结构和数学对象。仅命令执行成功不足以证明保存后的布局正确。

工作簿暂时被其他编辑操作占用时，等待后重试并保留当前编辑状态。将未完成的结构检查或视觉检查明确列为验证边界。

通用规则变化时更新本文。具体工作簿设置与局部例外只更新配置文档，并记录确认状态、范围和日期。
