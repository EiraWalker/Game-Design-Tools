# Excel 样式

沿用目标工作簿的样式完成局部编辑，保留计算公式、单元格富文本与可编辑数学对象。用户指定的文件是工作对象；从当前文件读取内容与布局。

## 样式依据

读取 [通用样式规则](references/style-guide.md)。采用主题预设、设置具体尺寸或维护布局快照时，再读取 [工作簿配置与布局参考](references/workbook-profile.md)。具体字体、颜色、行高、列宽、冻结窗格和局部差异集中维护在配置文档中。

用户当前要求优先，其次是目标工作簿已确认的规范与现有样式。配置文档中的通用示例供新表选择；已有表格按当前内容核实，局部编辑保留其他区域和用户已有调整。

## 编辑流程

1. **定位范围。** 读取相关工作表、单元格、计算公式、合并区域与数学对象，确定修改范围。写入设计内容时区分已确定规则、设计初稿和待定参数。
2. **识别角色。** 区分主标题、章节标题、小标题、表头、输入、计算结果和说明。优先复制同一工作表中相同角色的样式；按当前列宽下的实际换行设置表头行高。
3. **保留数学结构。** 使用能够保留现有数学对象和富文本的编辑方式；复杂工作簿优先原生 Excel 编辑或 COM。行内上下标使用真实单元格富文本，分式、分段等二维结构使用原生 OfficeMath。展示公式与 Excel 计算公式分别处理。
4. **适配公式行高。** 按通用规则的「公式展示区行高」同步调整承载行、公式框高度和垂直位置。多行展示区按总高度处理，检查下方对象仍在所属区域。
5. **核对保存结果。** 检查格式、换行、合并与对象；通过实际显示、截图或导出预览检查长表头和数学结构的裁切、遮挡及错位。涉及计算时验证代表性输入与阈值。对照修改前内容确认其他区域保留，交付实际保存文件与修改位置，并说明未完成的验证。

## 长期维护

- 通用编辑原则维护在 `references/style-guide.md`；工作簿特有设置、具体参考值及布局快照维护在 `references/workbook-profile.md`，注明适用范围、确认状态与更新日期。
- 单次局部例外只记录在对应区域，用户确认持续沿用后再调整适用规范。
- 行号、列宽或章节变化时更新相应快照；快照用于理解布局，执行前仍读取当前文件。
