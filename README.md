# Game Design Tools

游戏设计工具与可复用技能集合。

## SKILLS

- [Excel Style](SKILLS/excel-style/README.md)：Excel 表格样式维护，保留原生数学公式，适配公式展示区行高；具体字体、配色、列宽和布局参考独立维护。

各工具的使用方法、环境要求与许可见对应目录。技能安装时复制相应技能目录，保留其内部相对结构。

新增技能放在 `SKILLS/<skill-name>/`，新增插件放在 `Plugins/<plugin-name>/`；其他独立工具按用途设置目录，并在本页添加入口。所有目录由本仓库统一维护。
