# 工作簿配置与布局参考

维护日期：2026-10-05。

本文集中维护易变设置：字体、颜色、尺寸、列宽、冻结窗格、布局快照和局部差异。下列内容为去除业务含义的可选示例，不代表任何现有工作簿的实际布局。新增表格可选用；已有表格优先使用当前样式与用户确认的规范。

采用某项示例后，为目标工作簿记录适用范围和确认状态。工作簿名称、路径及业务字段等识别信息存放在使用方自己的配置文档中；公开分享配置时使用匿名标识。

## 字体与行高预设

字号和行高均使用 pt（磅），两者独立设置。以下值需要结合当前字体和内容验证；字体不可用时，选择能正确显示相应文字与数学结构的替代字体，并重新检查布局。

| 角色 | 字体参考 | 字号参考 | 行高参考 |
| --- | --- | --- | --- |
| 工作表主标题 | LXGW Marker Gothic / 霞鹜漫黑 | 24 | 40 |
| 章节标题 | LXGW Marker Gothic / 霞鹜漫黑 | 18 | 34 |
| 章节内小标题 | LXGW Marker Gothic / 霞鹜漫黑 | 12 或 13 | 按内容 |
| 单行表头 | LXGW Marker Gothic / 霞鹜漫黑 | 11、11.5 或 12 | 20 |
| 两行表头 | 与同表表头一致 | 与同表表头一致 | 40 |
| 正文、字段、输入 | MiSans | 11–12 | 按内容 |
| 补充说明、脚注 | MiSans | 10.5–12 | 按内容 |
| 原生数学公式 | Cambria Math | 保留原有字号 | 按通用规则适配 |

工作簿确认采用本预设时，同一表头行只要一个单元格显示两行文字，整行采用两行表头行高。更多行文字重新适配；正文和公式展示区采用各自的高度。

### 公式尺寸参考

初始估算可使用：内容高度加文本框上下内边距，再加约 8 pt 的展示区上下留白；向上取到 4 pt 的倍数。单行展示区可从 32 pt 起评估。这些值是可调整的起点，实际渲染决定最终高度。

| 匿名公式示例 | 字号参考 | 展示区高度参考 |
| --- | --- | --- |
| 单行表达式 | 17 pt | 40 pt |
| 两行分段表达式 | 17 pt | 60 pt |
| 含分式的表达式 | 17 pt | 56 pt |

公式长度、结构、字体或字号变化时重新测量。多行展示区使用总高度，将合适的高度分配到各行。

## 列宽与布局示例

列宽使用 Excel 列宽单位，不是 pt；以下为匿名布局示例，不能据此覆盖当前工作簿。

| 布局标识 | 列宽参考 | 可选布局 |
| --- | --- | --- |
| 六列参数与说明布局 | A：19.63；B:E：22.63；F：26.63 | 标题可覆盖 A:F；可不冻结窗格 |
| 七列长说明布局 | A：10.63；B：25.63；C：23.63；D：29.63；E：22.63；F：66.63；G：32.63 | 标题可覆盖 A:G；可冻结顶部 3 行 |
| 十二列参数矩阵 | A：21；B:F：17；G：11；H：12；I：11；J:L：18 | 标题可覆盖 A:L；可冻结顶部 4 行 |

同一工作表的分区可以使用不同合并宽度和表头字号；新增区域优先复制相邻同角色区域，不根据上述示例重新合并整表。

数字格式按字段单独记录，例如百分比、`0.0` 或带单位的自定义格式。显示格式与底层值分别核实。

## 目标工作簿的配置记录

用户确认持续使用某项设置时，在使用方配置中记录以下信息；仅供一次使用的调整标为局部例外。

| 记录项 | 需要记录的内容 |
| --- | --- |
| 配置标识 | 使用方自定的工作簿或样式标识 |
| 适用范围 | 工作表、分区、单元格角色或范围 |
| 状态 | 已确认规范、局部例外、待定方案或布局快照 |
| 日期 | 确认日期与最近核实日期 |
| 字体和主题 | 实际字体、字号、颜色、边框及加粗状态 |
| 尺寸与布局 | 行高、列宽、合并区域、冻结窗格、数学对象锚定 |
| 数字格式 | 字段对应的单位、精度与显示格式 |
| 例外 | 当前需保留的局部差异及适用范围 |

布局快照反映指定日期的文件状态；编辑前读取当前文件核实。更新样式预设不自动触发历史工作簿的全表改版。
